# 搜索框和快捷方式图标底衬透明度

在“外观 → 搜索框”调节搜索框透明度，在“外观 → 快捷方式”展开设置后调节图标底衬透明度。两个滑块独立，范围为 0–100%，支持拖动实时预览、数字输入、键盘方向键和重置按钮。

0% 保留原有底色，100% 完全透明；这是在原有主题底衬上增加透明度，而不是使原有半透明底色变为不透明。默认 0% 不改变既有外观。文字、favicon、快捷方式名称及“添加快捷方式”按钮不受影响，搜索建议列表保持原来的可读背景。

设置在松开滑块或完成数字输入后保存，刷新和其他新标签页同步恢复；保存失败回退到最近成功保存的数值，并提示重试。设置随现有浏览器偏好保存，不新增权限。

源码与最终安装包在隔离 Edge 中验证了两个底衬的实际背景 alpha、文字／图片不变、数字输入、Home／End 键、100% 透明、跨标签同步、刷新恢复和重置。浅色桌面及深色手机均已检查；解析／保存回退单元测试、类型／构建／资源检查、四语言文案审计和 403 项界面测试通过。偏好已注册到现有备份导出／导入列表，旧设置缺少此项时保持原外观。
